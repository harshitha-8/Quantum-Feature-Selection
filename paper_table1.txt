================================================================================
ABSTRACT NUMBERS (Copy-Paste Ready)
================================================================================

Dataset: 1,549 UAV images of cotton fields (869 post-defoliation, 680 pre-defoliation)
Features: 14 handcrafted features (7 color indices + 5 GLCM texture + 2 derived)
Evaluation: 5-fold stratified cross-validation with SVM-RBF classifier

Key Results:
- Clean Data: All methods achieve 100% accuracy (perfectly separable classes)
- QFS-4 selected features: Std_ExG, Mean_RBR, Mean_B, Correlation
- QFS-4 achieves 89.4% average accuracy under fog/glare/shadow perturbations
- QFS-4 feature redundancy: |r|=0.596 (vs 0.798 for MI-4)
- All-14 features catastrophically fail under fog (45.3% accuracy, 97.5% FPR)

Abstract Sentence Examples:
"Our hybrid quantum-classical approach selects 4 features from 14 candidates,
achieving 100% accuracy on clean data and 89.4% average accuracy under
environmental perturbations (fog, glare, shadow), while reducing feature
redundancy by 25% compared to classical Mutual Information selection."

"On 1,549 UAV images, the quantum-selected subset [Std_ExG, Mean_RBR, Mean_B,
Correlation] maintains 83.5% accuracy under fog conditions where the full
14-feature baseline drops to 45.3% with 97.5% false positive rate."

================================================================================
SELECTED FEATURES SUMMARY
================================================================================

QFS-4 Selected Features (Recommended):
1. Std_ExG      - Standard deviation of Excess Green index
2. Mean_RBR     - Mean Red-Blue Ratio
3. Mean_B       - Mean Blue channel intensity
4. Correlation  - GLCM texture correlation

MI-4 Selected Features:
1. Std_ExG      - Standard deviation of Excess Green index
2. Mean_ExG     - Mean Excess Green index
3. Mean_RBR     - Mean Red-Blue Ratio
4. Mean_B       - Mean Blue channel intensity

Key Difference:
- QFS-4 includes Correlation (texture) instead of Mean_ExG
- This reduces redundancy: Std_ExG and Mean_ExG are highly correlated
- Correlation captures texture information that color indices miss

================================================================================
KEY TAKEAWAYS FOR PAPER
================================================================================

1. CLEAN DATA: All methods achieve perfect classification, demonstrating
   that cotton defoliation is a well-separated binary classification task.

2. ROBUSTNESS: Feature selection is CRITICAL for deployment robustness.
   Using all 14 features leads to catastrophic failure under fog (45% acc).

3. QUANTUM ADVANTAGE: QFS-4 achieves comparable robustness to MI-4 while
   selecting more complementary features (lower redundancy |r|=0.596).

4. PRACTICAL RECOMMENDATION: For deployment, use QFS-4 features with
   fog-specific data augmentation during training.

5. FALSE POSITIVE RISK: All-14 has 97.5% FPR under fog - this would cause
   farmers to miss defoliation timing on nearly all fields during foggy
   conditions. QFS-4 limits worst-case FPR to 25.4%.
