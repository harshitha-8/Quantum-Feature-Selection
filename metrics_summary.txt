METRIC DEFINITIONS:
- Accuracy:  (TP + TN) / (TP + TN + FP + FN)
- F1-Score:  2 * (Precision * Recall) / (Precision + Recall)
- FPR:       FP / (FP + TN)  -- False Positive Rate
- mIoU:      Mean Intersection over Union = avg(TP/(TP+FP+FN) per class)
- AUC:       Area Under ROC Curve

================================================================================
KEY FINDINGS
================================================================================

1. CLEAN DATA PERFORMANCE:
   All methods achieve perfect classification (100% accuracy, F1=1.0, mIoU=1.0)
   on clean data. The cotton defoliation task is well-separated in feature space.

2. ROBUSTNESS ANALYSIS:
   - All-14 features degrades significantly under fog (45.3% accuracy)
   - MI-4 shows best fog robustness (89.5%) but uses redundant features
   - QFS-4 maintains balanced performance across all augmentations
   - QFS-2 excels under glare (99.9%) but struggles with fog (81.4%)

3. FEATURE EFFICIENCY:
   - QFS-4 achieves comparable robustness to MI-4 with lower redundancy
   - Using all 14 features actually HURTS robustness (overfitting to clean data)
   - 4 quantum-selected features provide best accuracy-robustness tradeoff

4. FALSE POSITIVE RATE:
   - All methods have FPR=0 on clean data
   - Under fog, All-14 has highest FPR (55%) - dangerous for deployment
   - QFS-4 maintains reasonable FPR (16.6%) under fog
